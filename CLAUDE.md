Thoth é uma aplicação web para auxiliar nos estudos e execução de um projeto, no caso, meu TCC.

- Deve ser possível fazer anotações diversas
- Deve ser possível adicionar artigos/PDFs e, para cada 1, marcar como lido, "necessário ler", bem como ser possível escrever anotações sobre cada 1
- No momento, não tenho interesse em publicar esse código e hospedalo na rede, portanto irá rodar localmente
- A ideia é funcionar como uma junção de um notion, escalidraw, obsidian, etc;
- Deve ser possível montar diagramas
- Deve existir uma lista de "to do", com detalhamendo para cada tarefa
- A qualquer mudança, atualize a documentação impactada (readme e diagramas)

- Sobre o código em si:
    Backend deve ser feito em Typescript, e o Front em react; 
    Não haverá login;
    Para persistência de dados, pode ser utilizado um banco de dados relacional ou não relacional, ou até mesmo arquivos JSON, dependendo da complexidade e das necessidades do projeto;

- Sempre verifique o conteúdo em Necessidades.md para verificar se há algo a ser feito. Sempre que algo for feito, marque como concluído.
